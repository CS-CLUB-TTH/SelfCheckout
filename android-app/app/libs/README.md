# Zebra Link-OS SDK Library Folder

Place the Zebra Link-OS SDK JAR file here:

## Download Instructions

1. Go to: https://www.zebra.com/us/en/support-downloads/software/printer-software/link-os-multiplatform-sdk.html
2. Download the "Link-OS Multiplatform SDK" for Android
3. Extract the downloaded file
4. Copy `ZSDK_ANDROID_API.jar` to this folder
5. Rebuild the Android project

## Note

The app will work without the Zebra SDK using direct USB communication,
but the Zebra SDK provides better printer management and error handling.
